How to take the English typing test

This online typing test runs in your browser, with no account and nothing to install. Choose a test length, click the typing area and copy the passage exactly as it appears. The clock starts only when text first appears in the box, so you can settle in first. Spaces, capital letters and punctuation are part of the passage. Keep the source text in view rather than trying to remember a whole sentence. The task is to copy accurately, not to write a better version of the paragraph.

Use the English test for English text. If you normally work in Vietnamese, switch to the Vietnamese typing test instead of treating the two scores as interchangeable. Check your operating system keyboard layout before starting. A misplaced quotation mark may come from a layout mismatch rather than a forgotten key. If you have just changed keyboards, type a few ordinary characters somewhere else first.

Choose a test length: 1, 5 or 10 minutes

Decide the length before you start and keep it the same when you compare runs: a one-minute result and a ten-minute result answer different questions, and neither replaces the other. Fifteen and thirty seconds are also available, but one hesitation takes up a large share of such a short run, so treat a surprising score there as something to check rather than a new level. The clock does not pause when you look away or switch tabs; if you are interrupted, start a fresh run.

How WPM, accuracy and errors are calculated

What the speed number counts

In this test, WPM is the number of characters currently in the input box divided by five, then divided by elapsed minutes. The displayed value is rounded. It counts the text still entered, including characters that do not match the passage. It is not a count of dictionary words and it does not subtract a separate error penalty. Spaces and punctuation take positions in the text too. That is why a single run works as both a WPM test and a typing accuracy test: the speed number tells you how much text is in the box, and the accuracy number tells you how much of it you could keep.

A worked example

Suppose, as an illustration, that you have 250 characters in the box after one minute. The speed is 250 ÷ 5 ÷ 1, or 50 WPM. If 240 of those characters match the expected positions, accuracy is 240 ÷ 250 × 100, or 96%, and the current error count is ten. Read the two together: 50 WPM at 96% accuracy is the whole result, not just the first number.

What happens when you correct a mistake

Accuracy compares the current input with the passage position by position. If you remove a wrong character and replace it correctly, that mismatch disappears from the current error count. The time spent correcting still belongs to your run. A missing space can shift later characters out of alignment, producing several highlighted mismatches until you fix the original omission. Look back to where the mismatch started before replacing a whole line.

I do not want you to leave this page with only the largest WPM number in mind. I would rather you know whether that pace lets you produce text you can use. Read speed, accuracy and the passage together. A lower result with a clear explanation gives you a more useful practice target than a personal best you cannot reproduce.

Compare typing speed results and consistency

Passage order, punctuation, familiarity with the words and the amount of correction all change the task. So do your device and input method. If you have copied the same material several times, you may start anticipating it. That tells you how well you know that material, not how you will type a document you have never seen.

For a simple comparison, use the same language, duration, keyboard and correction approach. Note anything unusual, such as an interruption or a recent layout change. Complete a run, read the result, and choose one detail to work on before repeating it. A speed typing test invites you to keep restarting until a flattering score appears; resist that, because it hides the ordinary attempts you wanted to understand.

What consistency can tell you

Consistency summarises how much the WPM samples taken during the run varied. A higher value means those sampled speeds varied less relative to their average. It describes how even your pace was in this test; it is not a grade for your technique or your attention. A pause to read ahead may affect it. The first few live numbers are particularly changeable because little time has elapsed.

There is more about the unit itself in what WPM means, then return for another run when you have a specific question. This page explains the calculation used by the current test; other tools may count corrections or errors differently. Keep a short note of the duration and input conditions alongside any score you want to compare later.

Check your keyboard and input method before testing

A physical keyboard and a phone keyboard involve different movements. Autocorrect, suggestions, touch input and unfamiliar key spacing all change the task as well. This is a keyboard typing test, not a keyboard tester: it measures the input it receives and does not check whether every physical switch on your keyboard works. If you are trying to track down a dead key or a rollover problem, a speed score will not find it.

Use the device that matches the task you want to understand, and say which device you used when sharing a result. After changing a keyboard layout, take time to confirm where the required symbols are. If you use a different language version, read its input instructions: some versions measure phonetic input rather than finished converted text. Their WPM values are not a single language-independent ranking.

A first typing test for beginners and kids

If you still look for each key, do not start with ten minutes. Take a 30-second or one-minute run and read it as a map, not a score. Which letters made you stop? Did you press Shift with the same hand that types the capital letter? Did one missing space turn the rest of the line red? The passages are ordinary English prose with capitals, commas and apostrophes, so a first run also shows you how much punctuation slows you down, not only letters.

My view is that a beginner should not take this test every day. Repeating it mostly trains you to hunt for keys faster with two fingers, and that habit is harder to undo than a slow start. Learn the home row and 10 finger typing in the typing course first, then come back once a week and use the same duration each time. I would take a slow, accurate result after a week of lessons over a fast one you got by looking at your hands.

Children can take the same test; there is no separate mode for kids. The passages were written for adult readers, so read the first lines together, choose 15 or 30 seconds, and talk about the red characters rather than the WPM. You don't need an account, and the history stays in that browser.

Choose typing practice from your test results

If errors collect around the same letters, practise a short piece containing those letters and notice the first wrong movement. If capitals and punctuation interrupt you, choose text that contains them rather than repeating an easy lowercase sentence. Free typing practice lets you paste a passage for that purpose. It uses correct-position characters in its WPM calculation, so its speed is not calculated exactly like this test.

If finding the keys is the main obstacle, the typing course gives you a sequence of exercises. For help with hand placement, use the touch typing guide. If you already know the keys, choose a smaller task: keep spaces accurate, use the intended Shift key, or read one short phrase ahead. None of these is a condition for passing this test; they are simply good next steps.

Questions about timing, corrections and result history

Does clicking the box start the clock?

No. The timer starts when the input first contains text. Clicking the passage or focusing the box lets you get ready. Once the run has started, waiting and correcting both use time.

Can I use Backspace?

Yes. You can remove and replace text. The displayed errors describe mismatches in the current input, rather than a permanent tally of every wrong key you pressed. Correcting changes that input while the clock continues.

Why did several characters turn wrong after one mistake?

The comparison uses character positions. A missing or extra character can put later text in the wrong positions. Find the first mismatch, including any missing space, and correct the alignment before continuing.

Will I see the same passage again?

The test assembles its text from a collection of passages and changes their order. Repeated material can occur. Familiarity with a passage is one reason to describe your test conditions when comparing results.

Where are earlier results kept?

Completed test records are kept in this browser using local storage when available. English and Vietnamese tests share this local history. It retains up to fifteen records, and the chart offers seven-day and thirty-day views. Clearing browser data or changing browser or device can leave you without that history.

Does the progress chart compare only one duration?

No. Its time-window summary can contain tests of different lengths. The result comparison uses a previous record of the same duration. Check the duration before interpreting a change as an improvement in the same task.

Is one short type test enough to tell my real speed?

It gives you today's sample, not a fixed level. Take three runs of the same length across a week and read the middle one; a single fast run often owes a lot to an easy passage.

Can this result certify my typing speed?

This is a self-directed browser test, not a supervised examination or typing certificate. Use it to observe your own work. If a school or employer specifies a test, follow its language, duration, scoring and supervision rules.
