개인정보처리방침

짧게 말하면, 우리는 개인정보를 수집하지 않아요. 과 진도와 점수는 내 브라우저에 저장되고, 우리에게 보내지는 일은 절대 없어요.

최종 수정일: 2026년 9월 26일
이 글은 번역본이에요. 영어판과 내용이 다르면 영어판이 우선해요. English

1. 운영자

typingease.site는 TypingEase가 운영해요. 개인정보와 관련된 일은 무엇이든 support@typingease.site로 메일을 보내 주세요.

2. 수집하지 않는 것

  • 계정, 이름, 이메일 주소, 비밀번호가 없어요. 서비스에 가입 절차가 없어요.
  • TypingEase는 쿠키를 설정하지 않아요.
  • 방문 분석, 광고, 추적 스크립트가 없고, 데이터를 팔거나 공유하지도 않아요.
  • 강의, 시험, 게임에서 입력한 내용은 브라우저 안에서 처리되고 우리에게 보내지지 않아요.

3. 내 기기에 저장되는 것

진도를 기억하기 위해 사이트는 내 기기에서 브라우저의 로컬 저장소(localStorage)를 써요. 여기에는 과 진도와 별, 배지, 타자 시험 기록, 게임 최고 점수, 하루 목표와 연속 기록, 자판과 소리 설정, 고른 언어가 저장돼요. 또 사이트는 서비스 워커(service worker)를 설치해서 사이트 자체의 페이지와 파일 사본을 보관해요. 그래서 더 빨리 열리고 오프라인에서도 작동해요.

이 정보는 내 기기 밖으로 나가지 않아요. 진도 페이지의 “기록 지우기” 버튼을 누르거나, 브라우저 설정에서 typingease.site의 사이트 데이터를 지우면 언제든 삭제할 수 있어요.

4. 제3자

  • 호스팅. 사이트는 Cloudflare Pages에서 호스팅돼요. 다른 웹 호스트와 마찬가지로 Cloudflare는 페이지를 전달하고 사이트를 악용에서 보호하기 위해 IP 주소, 브라우저 종류 같은 기술 데이터를 처리해요. Cloudflare의 개인정보처리방침을 참고하세요.
  • 글꼴. 페이지는 Google Fonts에서 글꼴을 불러오기 때문에, 브라우저가 IP 주소를 포함한 요청을 Google 서버로 보내요. Google의 개인정보처리방침을 참고하세요.

우리는 이 제공업체들로부터 우리 자신이 쓸 개인정보를 받지 않아요.

5. 어린이

서비스는 나이에 상관없이 누구나 이용할 수 있고, 어린이를 포함해 누구에게서도 개인정보를 수집하지 않아요.

6. 이용자의 권리

우리는 이용자에 관한 개인정보를 전혀 갖고 있지 않기 때문에, 우리 쪽에서 열람하거나 정정하거나 삭제할 것이 없어요. 내 기기에 있는 데이터는 위에서 설명한 대로 이용자가 직접 관리해요. 질문이나 요청이 있으면 위 주소로 연락해 주세요.

7. 이 방침의 변경

사이트가 데이터를 다루는 방식이 바뀌면, 예를 들어 나중에 방문 분석을 추가하게 되면, 변경이 적용되기 전에 이 페이지와 날짜를 먼저 고칠게요.
