# TypingEase — product & SEO context

Read by the SEO skills (seo-audit, schema, programmatic-seo, site-architecture, ai-seo) before they ask
questions. Facts only; the repo rules in DECISIONS.md ("QUY TẮC CHUNG") win over any skill advice.

## Product
- **What:** free touch-typing course that runs in the browser (a web app / SaaS-style tool, no signup,
  no payment today). Domain: https://typingease.site
- **Differentiator:** every course is built on the learner's REAL keyboard layout (AZERTY, QWERTZ,
  BÉPO, Dvorak, Colemak, JIS, Arabic, InScript, Hangul 2-set, Zhuyin…), not on an American QWERTY
  with relabelled keys. 27 languages, 55 courses ("keyboard families"), 119 layouts. Vietnamese
  course teaches Telex diacritics.
- **Audience:** people learning to type in their own language, on their own keyboard; students,
  office workers. Primary markets: Vietnam (original site) and English; then every listed language.
- **Competitors (do not copy their content):** typing.com, typingstudy.com, keybr.com,
  monkeytype.com, 10fastfingers.com, ratatype.com.
- **Goal of SEO:** rank for "learn touch typing / typing course / typing lessons" + layout-specific
  queries ("azerty typing course", "bépo apprendre", "clavier arabe cours", "注音 打字 練習" …) in
  each language, and for the Vietnamese tool pages (kiểm tra tốc độ gõ, luyện gõ 10 ngón).

## Hard constraints (from the repo rules)
- Static vanilla HTML/CSS/JS. NO framework, NO build step, NO new dependency, no server code.
- Keep existing URLs, sitemap entries, canonical and hreflang working. Redirect pages are
  `meta refresh` stubs (GitHub-Pages-style static hosting, `CNAME` present) — no server redirects,
  no custom HTTP headers.
- Many pages are GENERATED — edit the generator/data, never the output by hand:
  - course roadmaps `/<lang>/<roadmap>/`: `bai-hoc/generate.mjs` + `bai-hoc/config.<lang>.mjs`
    (hreflang table `ALTERNATES` lives in generate.mjs)
  - family players + family roadmaps: `scripts/build-family-pages.js`
  - progress pages `/<lang>/<slug>/`: `scripts/build-progress-pages.mjs` + `tien-do/text/<lang>.mjs`
  - taster pages `/try/…`: `scripts/build-tasters.js`
  - landing `/` text per language: `landing-i18n.js` (runtime), HTML source is English
  Each has `--check`; run it after changing the generator.
- After any change: verify in real Chrome (playwright-core at C:/Users/KHAI/node_modules), console
  clean, and run `scripts/e2e.js` (test 11e checks every sitemap URL is live and indexable; 11b/11c/
  11d/11f check redirects and cross-language links). Do not commit or push unless asked.

## URL structure
- `/` English landing + live keyboard/language picker (x-default). `/vi/` Vietnamese home.
  Vietnamese tool/article pages live at the root: `/bai-hoc/` `/hoc/` `/tien-do/`
  `/kiem-tra-toc-do-go/` `/luyen-tu-do/` `/luyen-phim-yeu/` `/cach-go-10-ngon/` `/wpm-la-gi/` …
- Each other language: `/<lang>/` home, `/<lang>/<roadmap>/` course overview (indexable, the main SEO
  page), `/<lang>/<learn>/` lesson player (`noindex`, app shell), `/<lang>/<progress>/` progress page
  (`noindex`, same template for all, not in sitemap). Extra keyboard families: `/<lang>/<family>/` (roadmap,
  indexable) + `/<lang>/<family>/<learn>/` (player, noindex). Language codes are lowercase in URLs
  (`/zh-tw/`), BCP-47 in `<html lang>`/hreflang (`zh-TW`).
- `/try/<code>/` taster pages exist only for layouts without a course.
